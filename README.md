# Daily Dapper (phone version)

A website version of the Daily Dapper Firefox extension, for checking off the skincare and grooming routine on a
phone. It's built from the extension's code by `tools/build-web.mjs`; don't edit these files directly.

It contains no routine data or tokens. On first use, open Settings and enter a GitHub repo and a token for it; they're
stored only in this browser. Progress syncs through that repo, so the phone and the computer show the same day.
