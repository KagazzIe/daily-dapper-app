Settings

Sync with GitHub

Your routine, check-offs and settings are saved as files in a private GitHub repo, so the extension and the phone website show the same day. Enter the same two values on each device.

Create a fine-grained token: Repository access → Only select repositories → your data repo; Permissions → Contents: Read and write. It's stored only on this device.

Reminders

Firefox on your computer shows these as notifications, only if there are steps left. This website can't send notifications, but the times sync to the extension.

The day rolls over at 4am, so a late evening routine still counts for the day before.

Streak

A streak day is one where every required step was done (optional steps, like the Wednesday mask, don't count). One missed day per week (Monday to Sunday) is a grace day: it doesn't break the streak or add to it. A second miss in the same week starts over.
